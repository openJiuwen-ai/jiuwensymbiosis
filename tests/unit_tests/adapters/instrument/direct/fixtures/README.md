# Frozen PR execution history

The legacy-*.json snapshots were generated by running the actual Runtime and
direct InstrumentSession with a synthetic adapter from
PR #85 commit f0bf5a0f0124f469c825d73435af84a8cdb84c08. They contain SQLite
iterdump output and retained lock/authority records after one successful call
or one lost response. No live hardware or external credentials were used.

The test substitutes only __LEGACY_ROOT__ filesystem locations, reconstructs
the old SQLite/lock files, and opens them through the current Runtime. It
changes the deployment envelope without regenerating invocation identities,
contract digests, parameter fingerprints or request keys. Archived process
exit is modeled explicitly to avoid future PID reuse.

The original execution commands and source revision are retained in the local
review validation material. These are test fixtures, not a migration utility.
