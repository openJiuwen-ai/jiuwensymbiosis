# 自包含 HTML 架构报告

仅在用户要求 HTML 交付时使用；审查范围、模型和证据要求由
[主技能](../SKILL.md) 定义。

## 文件与结构

遵循用户指定的输出位置；否则写入
`tmp/review-reports/review-architecture-change-<scope>-<short-sha-or-timestamp>.html`。
文件名包含足够信息避免覆盖已有报告。

按主技能的顺序展示结论、目标、原模型、新模型、变化、发现与证据。
复杂关系用依赖图、关键流程图和前后对照表；局部改动无需填满所有视图。
原始 diff 和较长代码放在可折叠证据区，不作为报告主体。

## 呈现与安全

- 使用 UTF-8 HTML5，内嵌 CSS，不加载远程脚本、字体、样式或图片。
- 图使用 HTML/CSS 或无脚本内联 SVG；报告离线可读。
- 仓库文本、代码和用户输入按插入上下文转义。链接目标也需验证，
  不将原始内容当作 HTML、脚本或可执行 URL。
- 提供清晰导航、键盘焦点、响应式布局和打印样式。
- 紧邻结论说明“最终合入决定由检视者作出”。

## 检查交付

确认文件存在、非空，结构和链接完整，无外部加载资源；
检查正文、图表与结论使用相同术语，每项发现均有证据。
有渲染工具时检查浏览与打印效果；只做静态检查时如实说明。
回复给出报告的绝对路径可点击链接及主要发现。
