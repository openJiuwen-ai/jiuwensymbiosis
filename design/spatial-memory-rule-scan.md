# Rule 单房间正式入口

基线 ee6e77e。范围：修复可复现的可见表面身份碎片；正式 memory scan CLI；单房间模拟实走验收。多房间、真机、KEV 均不在本次范围。

## 所有权

SpatialMemory 仍是唯一实体库。新增 exploration 只根据 RGB-D/位姿和当前补看任务产生候选，沿用 R0 效用；无场景真值、模型请求、物体清单。scan 管理采集、感知、事务提交、预算、取消与停止报告；不拥有硬件。Genesis scan port 复用 RobotSession、SafetyRail 同步验证与已有运动租约/实测停车。CLI 拥有会话与连接；不会停止外部服务。

本次 Genesis 执行使用 simulator_readback 位姿与既有静态场景整机导航准入，真值只在执行侧作为阻挡门控，拒绝绕路，不能反向作为探索收益或完成依据。不能替代轮编码器定位或未知环境整机安全验收。每个候选最多移动 0.2m 或转向 30° 后重新观测。相机代理路径不授权机器人运动；不直接采用实验相机的 12cm 包络。

## 完成状态

停止原因、几何范围、物体清点分开。预算/取消/感知失败/运动失败/所有候选受阻均非完成。只有 RGB-D 在线可达连通区域的外邻边界全部被占据观测闭合时，范围才为 observed_enclosed_component；这不保证真实房间边界或隐蔽空间。几何完成还要求无前沿、连续至少三次观测低新增收益；有 open/deferred 任务则物体记忆尚有缺口。无任务也只能报告 no_known_gaps，inventory_complete 不会自动成为 true。

## 数据兼容

遮挡采用独立整帧深度，剔除明显在前景之后的历史表面；不按当前检测掩膜裁剪，不将无深度当遮挡。关联版本升至 v7，增加 IoU≥0.90 的同帧近重复掩膜代表/别名（原始掩膜全保留，一帧仅一票）。旧库可只读，新增写入必须重新回放到新库；保留原始证据，不改历史库。

## 验收（实施前固定）

1. 遮挡身份回归由红变绿；无深度/容纳关系/同类相邻对象/关联歧义测试保持通过。
2. 固定 0030、0037、0025 的原始 RGB-D/检测回放，使用已有人工锚点及配对定义；报告所有变化，不能只数 entity ID 分配。若误合并或正确配对退化，不将该修复默认发布，定位后再验。
3. 结束状态反例测试：预算、未知边界、遮挡疑问、取消、动作拒绝、停车未确认。部分完成不能报告整个房间完成。
4. 实际 GPU、YOLOE 与 MOZ1 单房间，正式 CLI 至少两个独立运行（正常有界闭环和预算中止）；正常运行至少 4 个成功观测、实际轮式运动与实测停车，数据库可重开且固定检测回放一致；无 KEV 启动或调用。
5. 核心测试、格式/lint、安装入口验证。动作拒绝单独测试，不把所有动作受阻当实走通过。

记忆整体召回仍需后续独立规模验证，本次不会声称全面解决全房间清点或任意遮挡身份。

## 2026-11-09 验收结果

限定范围通过：独立安装 wheel 的正式 CLI，在受控家具单房间中完成 10 帧真实 YOLOE 入库、9 次实测轮式转向及停车，另一次一帧预算停止；两次冻结回放四张业务表完全一致。全部报告保留 `scan_complete=null`。固定 34 对身份锚点正确配对 16→20，无新增误合并；仍有 14 对未决。

本次没有证明平移探索：头部相机下俯约 50°，在线相机高度切片生成的候选以原地转向为主；实际平移仅为微小漂移。首次试验的出生点被整机准入拒绝，原始失败证据保留，未放宽安全检查。完整结果与局限在 `outputs/rule-single-room-acceptance-20261109/report.md`。多房间扩展等待用户指令。
